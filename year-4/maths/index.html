A simple way to practise

How to use Year 4 maths practice

These practice sets cover selected Year 4 topics. Read the labels and units carefully, explain how you chose an answer, and use the feedback to decide what to practise next. They support learning and do not replace a full curriculum assessment.

  • For a scale, find the difference between two labelled marks and divide it by the number of equal spaces between them.
  • If a ruler does not start at zero, subtract the start reading from the end reading to find the object's length.
  • For area, cover the inside with equal square units, count whole squares and combine partial ones; area is different from the distance around the boundary.
  • Compare an angle with a square corner: smaller is acute; wider but less than a straight line is obtuse; beyond a straight line is reflex; a full turn is a revolution.
  • For a grid reference, read the column letter first and the row number second; use the map's north arrow to follow directions. For composite shapes, use cut-outs or tangram pieces: slide, turn or flip them to make a new picture, then name the shapes you used.
  • Compare like measurements in the same unit and check whether the answer is sensible for the object.
  • Try four activities: hide ruler or jug labels and work out an interval; make two shapes from 12 equal paper squares and compare area/perimeter; make angles with two strips of card and compare them with a square paper corner; draw a 4 × 4 grid of a familiar room and use references to describe a route.
  • Run a mini survey: ask a neutral question, record answers in a tally table, choose a chart with clear labels and a key, then write what the data shows. For chance, toss a coin 20 times, tally heads and tails, repeat the experiment and compare the results; do not change the tally to match a prediction.

Build a fraction and decimal family

Draw one strip and divide it into 2 equal parts. Shade one part. Draw the same-sized strip divided into 4 parts, then 8 parts. Shade the same amount each time.

Write the equivalent fractions, then mark the amount on a number line from 0 to 1. Try the same with one quarter and with tenths. Explain how you know the amounts stay equal when the number of parts changes.

Example: one half = two quarters = four eighths = 0.5. The shaded amount stays the same; only the way it is divided and written changes.

Use place value to multiply and divide by tens

Break a multiple of ten into a basic fact and a power of ten. For example, 24 × 30 = 24 × 3 × 10 = 72 × 10 = 720.

Try 32 × 40 and 2,800 ÷ 40. For division, divide both numbers by 10 first: 2,800 ÷ 40 = 280 ÷ 4. Explain why changing only one number would change the answer.

Choose an efficient strategy and check it

For addition and subtraction, look for a friendly number: 398 + 247 = 400 + 247 − 2 = 645. For multiplication, split a factor: 16 × 12 = 16 × 10 + 16 × 2 = 192. For division, use a related multiplication fact: if 18 × 52 = 936, then 936 ÷ 18 = 52.

  1. Try 602 − 298 and 24 × 25. Write or explain a strategy that makes each calculation easier.
  2. Estimate first, then use a calculator to check one answer. If the result seems unreasonable, check the operation and the numbers you entered.
  3. Compare your method with another method. A calculator checks a result; explaining your choices shows how you worked it out.

Practice focus: this activity supports strategy choice and digital checking. The multiple-choice quiz cannot show whether a learner independently selects a tool or explains a method in their own words.

Check a spending plan with an estimate

Round prices to friendly amounts before adding or multiplying. For example, 4 lunches at $6.80 each will cost about 4 × $7 = $28. The exact total is $27.20, so the estimate is a useful check.

  1. You have $50 for a visit. Estimate the cost of 4 tickets at $11.80 each and $6.50 parking.
  2. Decide whether the $50 budget is likely to be enough. Explain which prices you rounded and why.
  3. Work out the exact total after estimating. Compare the two amounts and explain whether the exact answer is reasonable.

Example check: about 4 × $12 + $7 = $55, so the budget may be short. The exact total is $53.70. An estimate helps check reasonableness; it is not the exact amount to pay.

Model a school event problem

Six classes each send 24 students to an assembly. Eighteen staff members also attend. How many people need a seat?

  1. Choose the operations and write a number sentence before calculating.
  2. Work out the total, then state what your answer counts.
  3. Explain why your number sentence matches the situation. Could you solve it another way?

Example model: 6 × 24 + 18 = 144 + 18 = 162 people. The number sentence counts six equal class groups, then adds the staff.

Create and test a number algorithm

Try this set of ordered instructions: start at 4 and record the number. While it is less than 40, add 6 and record the new number. Stop when the condition is no longer true.

  1. Follow the steps and write every number, including the start and the number that reaches or passes 40.
  2. Describe the pattern and explain when the algorithm stops.
  3. Create another algorithm using addition or multiplication, with at least one decision. Write the steps so a classmate can follow them exactly.
  4. Use a spreadsheet or calculator to check a longer run of your rule. Compare the tool's output with your predicted pattern.

Example: 4, 10, 16, 22, 28, 34, 40. Each step adds 6; when the current number is not less than 40, stop.

Keep both sides of an equation equal

The equals sign means “has the same value as”. Try 26 + 39 = □ + 23. Notice that 26 is 3 more than 23, so the missing number must be 3 more than 39: 42.

  1. Solve 54 − 18 = 50 − □ by finding the value of one side, then balancing the other.
  2. Try a relationship strategy without calculating both totals. Explain how changing both addends can keep a sum the same.
  3. Write a balanced equation with an unknown on one side and an addition or subtraction expression on the other. Swap it with someone and explain how you know both sides are equal.

Check: 54 − 18 = 36, so 50 − □ must also equal 36. The missing number is 14. You can substitute it back to check both sides.

Count fractions past one whole

Draw a number line from 0 to 2. Mark 0, 1 and 2, then divide each whole into thirds. Count forward by thirds and label every point, including the mixed numbers.

Try again with quarters. Which count reaches the same point as 1 1/2? Write that value as a mixed number and an improper fraction. Explain how the denominator sets the size of each step.

Example: 1/3, 2/3, 3/3 = 1, 4/3 = 1 1/3. Fractions keep counting after they pass one whole.

Investigate odd and even patterns

Use counters or quick sketches to test these sums: odd + odd, odd + even and even + even. Try two examples for each, then write a rule that always works.

Now test subtraction and multiplication. For each rule, find an example that supports it and explain why the result is odd or even. Check your rule with a different pair of numbers.

Hint: pair the objects. An even group has no leftover; an odd group has one. For larger whole numbers, the last digit tells you whether the number is odd or even.
