Plural spellings

Look at how the ending changes. Some plurals are irregular, and there is no single pattern for every word.

  • wolf → wolves
  • shelf → shelves
  • half → halves
  • calf → calves
  • tomato → tomatoes
  • potato → potatoes
  • photo → photos
  • city → cities
  • story → stories
  • church → churches
  • box → boxes
  • day → days

Word families

Notice the base word and the spelling changes as a prefix or suffix is added.

  • act → action → active
  • decide → decision
  • create → creation → creative
  • appear → disappear
  • possible → impossible
  • understand → misunderstanding
  • use → reuse → useful
  • move → movement

How to practise Year 5 spelling

Year 5 practice brings together word building, less common plurals and letter patterns that can represent different sounds. Try explaining the spelling choice as well as memorising the word.

  • For plurals, notice whether the word changes (child → children) or takes a regular ending; do not assume every word follows one rule.
  • For suffixes, find the base word and check whether its spelling changes before the ending is added.
  • In words such as though, through and tough, the same letter sequence can represent different sounds, so learn each word in context.
